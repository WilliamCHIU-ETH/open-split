# 04 垂直切片

每次只做一片，做完要能從使用者的動作看到結果。數學不變量從第一片就在，不能等最後才補。

切片 0 是這份 harness，不含產品功能。

## 1. 平均分帳與餘額

使用者能建立群組、加入已登入的自己、記一筆平均分的支出、看到餘額合計為 0。

包含：群組、支出、份額、餘額查詢、活動紀錄的第一筆。HTTP 不再對這些路徑回 501。

不包含：不平均分法、虛擬成員、結清寫入、多幣別、MCP、LINE。

Driver：`pnpm driver accept` 已經用假身份走平均分。這一片要改成打到 Worker，而不是只寫 JSON。證據仍貼 driver 輸出。

完成：`packages/core` 的性質測試仍過；一筆平均分支出的份額合計等於原金額。

## 2. 不平均分法與虛擬成員

使用者能用指定金額、百分比基點、份數來分，也能排除某些人。能先加一個還沒登入的朋友，稍後由他認領，歷史份額不改掛到別的成員。

Driver：`add-expense --split exact|percentage|shares`，以及 `add-member --virtual`。認領流程在這一片接上真的資料庫。

## 3. 結清與債務簡化

使用者看到建議轉帳（人數減 1 以內），並能把一筆結清寫進帳，餘額隨之歸零。可以留下收款方式文字。作廢一筆結清會回到活動紀錄。

Driver 的 `settle` 目前只印方案。這一片才寫入。

## 4. 多幣別

一筆支出可以不是群組預設幣別。匯率是兩個整數。換算在 `packages/core`，禁止浮點匯率。換完之後，餘額仍以群組預設幣別合計為 0。

## 5. OAuth 2.1 與 MCP

外部代理人可以走授權碼與 PKCE。沒有 `mcp_allowed` 的人被拒。不是群組成員也不能對該群呼叫工具。工具實作呼叫與網頁相同的服務層與 `packages/contracts`。

本機驗收繼續用假身份，不把假身份開到部署設定。

## 6. LINE Login、LIFF、分享卡片

LINE Login 成為主要登入。Google 維持次要。LIFF 打開的是同一套帳本，在裡面記帳必須可用。`liff.shareTargetPicker()` 能把 Flex 卡片分享到聊天。

不做聊天機器人。見 [ADR-0005](adr/0005-line-liff.md)。

## 7. 可選的官方帳號推播

群組可以綁一個 LINE `groupId`。官方帳號只 push 帳單或提醒，不接收、不回覆聊天。沒綁定的群組完全不碰 Messaging API。

## 每一片都要

- 對應 `docs/feature-map.md` 的項目。
- `pnpm check` 通過。
- PR 裡貼上 driver 證據。
- 不自動合併。
