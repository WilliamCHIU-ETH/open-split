# 01 產品檢視

`open-split` 是擁有者和朋友自己用的分帳服務，LINE 上的體驗對標 Lightsplit，而且 Agent 可以經 MCP 記帳。它跑在擁有者的 Cloudflare Workers 與 D1 上，不是公開服務。為什麼要做、做到哪算上線，見 [00 意圖](00-intent.md)。這一層只定「為誰解決什麼」，不寫表結構。

## 誰在用

- **記帳的人**：通常是擁有者。他會在網頁裡記，也會在 LINE 裡打開同一套帳本記。他還會對自己的外部代理人說話（例如「X 群 10 人裡只有這 5 人吃，我付了 3000 日圓，平均分」），由代理人透過 MCP 寫進同一本帳。
- **一起分的朋友**：不一定有帳號。可以先被記成虛擬成員，之後再用邀請連結認領。他們平常在 LINE 群聊天，不跟機器人對話。
- **外部代理人**：Grok Bot、Claude 等。它不是產品裡的模型。它用擁有者的 LINE 帳號經 OAuth 2.1 授權取得 MCP（[ADR-0009](adr/0009-mcp-identity-via-line.md)），呼叫與網頁相同的服務。

## 三個表面

1. **帳本網頁是主產品。** 要像一個做完的 SaaS，而不是後台。群組、邀請連結、虛擬成員、平均／指定金額／百分比／份數、排除某些人、多幣別與自訂匯率、即時餘額、最少轉帳的債務簡化、結清、分類與備註、收款方式說明、修改與作廢、完整活動紀錄。代理人的存在不能讓這個網頁變差。
2. **OAuth 2.1 MCP 伺服器**把同一套帳本引擎開放給外部個人代理人。帳號上的 `mcp_allowed` 是允許清單，資料層再檢查群組成員身份。MCP 工具與網頁 API 共用一個服務層、一套 Zod schema。
3. **LINE 是人與人之間的表面，不是聊天機器人。** LINE Login 是主要登入，所有人都能用。Google 不在上線範圍內。LIFF 是同一套網頁帳本在 LINE 裡打開，帶著 LINE 身份；在 LIFF 裡記帳是允許的。可以選擇把官方帳號綁到群組的 `groupId`，只用 Messaging API 安靜地推播帳單或提醒。朋友繼續在群裡聊天。擁有者對代理人說話發生在 LINE 外面。

「LINE 只做通知與分享」指的是：沒有對話式機器人，官方帳號只做單向推播。它**沒有**限制 LIFF 裡的網頁能做什麼。LIFF 能做的事與不能做的事寫在 [ADR-0005](adr/0005-line-liff.md)。

## 不做

- 不做內建的自然語言或決策模型。
- 不經手付款，不移動金錢。收款方式只是給朋友看的文字。
- 不做內建收據 OCR。外部代理人自己讀收據，再經 MCP 寫入。
- 不把 MCP 開放給每個登入的人。登入與 MCP 是兩回事，見 [ADR-0003](adr/0003-auth-separation.md)。

## 怎樣算好

- 同一筆帳，網頁與 MCP 算出的餘額相同。
- 分帳之後，群組的淨額合計為 0。四捨五入（實際是整數餘數）不多出、也不吃掉任何最小貨幣單位。
- 債務簡化之後，每個人淨額為 0，轉帳次數不超過參與者減 1。
- 虛擬成員可以先被記帳，稍後由本人認領，歷史不重算。
- 網頁在手機上、以及 LINE 的內建瀏覽器裡，都能完成記帳。代理人路徑不能拿掉這些畫面。
