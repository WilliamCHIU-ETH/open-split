# 00 意圖

這份文件回答「為什麼有 open-split」。其餘文件回答「怎麼做」。兩者衝突時，以這份為準；要改這份，先問擁有者。

- 狀態：已接受
- 日期：2026-11-21
- 來源：擁有者在 2026-11-21 與 Orchestrator 的對話。先前的決策經過多次 Agent 交接，有些脈絡遺失，這份把它補回來。

## 一句話

**一個我和朋友自己用的分帳服務：在 LINE 上的體驗跟 [Lightsplit](https://lightsplit.com/zh-tw) 一樣好，而且我的 Agent 是一等公民，可以替我記帳。**

## 為什麼自己做

擁有者原話：「我和朋友可以擁有像 Line Split 一樣的 SaaS 服務……體驗非常好，但它最終還是無法讓我的機器人（也就是 Agent）去操作這個記帳服務，所以我才想要自己做。」「這就是我的 homelab 成果，所以我希望直接做一個我自己的同時有相同的體驗，另外也不是要公開還是怎麼樣就是自己要用的。」

2026-11-21 查證：Lightsplit 從 2026-08 起也提供 MCP（`https://api.lightsplit.com/mcp`），但需要年繳 Premium，最多同時連兩個應用程式，教學只示範 Claude 與 ChatGPT，收據照片不保存，也沒說 Agent 寫入時會不會通知 LINE 群組。擁有者看過這些後，仍決定自己做。

所以 open-split 跟 Lightsplit 的差別不在功能數量，而在這幾點：

1. **自己掌控。** 帳、收據、權限、成本都在擁有者的 Cloudflare 帳號裡。這是 homelab，不是商品。
2. **任何 Agent 都能接。** 標準 OAuth 2.1 MCP，不綁特定客戶端，連線數也不設上限。擁有者自己的 bot（例如 OpenBot 上的 Agent）跟 Claude、ChatGPT 一樣能接。
3. **Agent-first。** Agent 不是外掛。見下方的設計原則。

## 誰用

- **擁有者**：記最多帳的人。在網頁、LINE 和自己的 Agent 三處記同一本帳。
- **朋友**：平常在 LINE 群聊天，用 LINE 登入，在 LIFF 裡看帳、記帳。不一定註冊，可以先當虛擬成員。
- **Agent**：擁有者的（之後也可能是朋友的）外部代理人，經 MCP 讀寫，權限不會超過它所代表的那個人。

不是公開服務：不做公開註冊頁、行銷頁、付費方案或多租戶管理。只有被邀請進群組的人用得到。

## 體驗目標（對標 Lightsplit）

- 在 LINE 群裡就能開始：分享邀請，朋友用 LINE 登入，打開就是帳本。
- 記一筆之後，群組裡的人知道有新的一筆（分享卡片或安靜推播）。
- 平均分、指定金額、比例、份數、排除某人、虛擬成員、多幣別與自訂匯率、最少轉帳結清、收款方式。
- 手機與 LINE 內建瀏覽器是主要場景，不是桌面網頁的縮小版。

## Agent-first 設計原則

1. **同一個服務層。** Agent 和網頁走同一套服務與 Zod 契約，算出的餘額必須相同。
2. **同一個身份。** Agent 用擁有者在網頁使用的 LINE 帳號授權（[ADR-0009](adr/0009-mcp-identity-via-line.md)），不用另一套帳號體系。
3. **權限跟著人。** Agent 只看得到、改得到它代表的那個人所在的群組。讀和寫分開授權。
4. **重送安全。** 寫入工具都可以帶冪等鍵；Agent 逾時重試不會多記一筆。
5. **看得出是誰記的。** 活動紀錄顯示「誰、經由哪個 Agent」記的，群組裡的人看得到。
6. **Agent 的寫入跟人的寫入一樣會通知群組。** 不要讓 Agent 記的帳變成沒人知道的帳。
7. **產品裡沒有模型。** 自然語言、讀收據、判斷要怎麼分，都是 Agent 的事。產品只提供正確、可驗證的工具。

## 上線的定義

擁有者在 2026-11-21 選定：**真實群組完整跑一次。**

上線指的是以下全部做到：

1. 部署到擁有者的 Cloudflare 正式網域，`PUBLIC_BASE_URL`、D1、KV、R2、LINE 憑證都是正式值。
2. 擁有者和一個真實 LINE 群組裡的朋友，用 LINE 登入，在 LIFF 裡記帳，並把卡片分享回群組。
3. 擁有者的 Agent 經 MCP（用 LINE 授權）記一筆，網頁與 LIFF 看到同一個結果，活動紀錄標示經由 Agent。
4. 結清一次，大家的餘額歸零。
5. D1 有可還原的備份方式，部署有退回方式，並且實際演練過一次。

在這之前，切片的「完成」只代表在本機驗收通過。

## 不做

- 不做內建的自然語言或決策模型，不做收據 OCR。
- 不經手付款，不移動金錢。
- 不做會回話的 LINE 聊天機器人。官方帳號只做單向推播。
- 不做公開註冊、計費或多租戶。

## 待擁有者確認

- 上線用的是哪個群組、哪次活動。
- 每月成本上限（目前假設維持在 Cloudflare 免費額度內，未經擁有者確認）。
- Repo 目前是公開的。服務是自用的，repo 要不要轉私有由擁有者決定。轉私有前要先確認 Codex 審查在私有 repo 仍可用。
